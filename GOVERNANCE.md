# Governance

Reweft initially uses a maintainer-led model. The maintainers listed in `MAINTAINERS.md` merge changes, manage releases, handle security reports, and steward compatibility and safety boundaries.

Routine decisions happen in reviewed pull requests. Material changes to public contracts, safety controls, inference routing, or compatibility use a public RFC unless disclosure would create a security risk. Maintainers seek reasoned consensus; if consensus cannot be reached, the active maintainers record a decision and rationale. A maintainer with a conflict recuses themselves.

New maintainers are added after sustained, trustworthy contribution and explicit approval by existing active maintainers. Inactivity alone does not transfer ownership. Removal for security, conduct, or prolonged inactivity is documented where privacy permits. No foundation, company sponsorship, or elected community body is claimed.
