# Code of Conduct

We are committed to a respectful, harassment-free project for everyone. Be considerate, critique ideas and code rather than people, respect privacy, and do not publish another person's confidential information. Harassment, threats, discriminatory conduct, sexualized attention, and sustained disruption are unacceptable.

Maintainers may edit or remove contributions and restrict participation when conduct is harmful. Report conduct concerns privately using GitHub's **Report content** flow or a private message to a listed maintainer. Do not open a public issue containing sensitive personal information. The maintainer will handle reports as confidentially as practical and disclose conflicts of interest.
