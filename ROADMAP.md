# Roadmap

The roadmap follows evidence, safety, and dependency order rather than date promises:

1. Authoritative contracts, isolation, source admission, and evidence provenance.
2. Native PostgreSQL and synthetic-estate end-to-end path.
3. Durable investigation, inference gateway, deterministic assessment, and exports.
4. UI onboarding, investigation, lineage, modernization, diagnostics, and accessibility.
5. Fixture-validated BW/report/pipeline imports and local target execution.
6. Authorized live connector/target validation, release hardening, and publication.

Items are intentions, not shipped claims. Acceptance status is tracked in `contracts/acceptance.yaml`.
