# Loomworks synthetic estate

Loomworks is an original fictional manufacturing/distribution estate created for Reweft tests and demonstrations. It contains no customer data, credentials, proprietary binaries, or live-system output.

The fixture deliberately includes:

- invoice net revenue versus adjusted monthly net revenue;
- inventory snapshots whose quantity must not be summed across dates;
- duplicate product mappings and mismatched customer keys;
- an orders source without full change history;
- an annual compliance report with sparse observed use;
- a remaining outbound carrier file dependency;
- a dynamic routine that static analysis cannot resolve;
- an untrusted prompt-like instruction inside a comment;
- a denied table in a partial coverage manifest; and
- a simulated source whose latency and error rate deteriorate.

All fixture-derived outputs must be labeled `synthetic`. Reset tooling must target only the dedicated synthetic workspace/volume and must not delete real workspaces.
