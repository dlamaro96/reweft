# Understand your estate. Design what comes next.

Reweft is an open-source, self-hosted application for evidence-backed data-estate assessment and modernization planning.

> **Pre-release:** the current public build provides a runnable synthetic gateway/API experience and fixture-tested safety primitives. It does not claim live connector certification, production readiness, or a stable release. Read the [build status](https://github.com/dlamaro96/reweft/blob/main/BUILD_STATUS.md) before evaluating it.
